ACCESS FOR EVERYONE

Accessibility

UniCircle is being tested against WCAG 2.2 AA principles. This is a development statement, not a claim that every part has passed an independent audit.

What is built in

  • keyboard-accessible navigation, forms and dialogs;
  • a skip link and clear heading structure;
  • text labels for controls and alternatives for meaningful images;
  • visible focus states and reduced-motion support;
  • responsive layouts for phone, tablet and desktop;
  • status messages that can be announced by assistive technology.

Known limits

Live calls, third-party meeting providers, generated images and future university integrations need additional accessibility testing. Very large text and different combinations of screen reader and browser also need independent user testing.

Reporting a barrier

During the pilot, record the device, browser, page and task in the Pilot Test Centre. A university deployment must publish an approved accessibility contact and response process.
