ACCESS FOR EVERYONE

Accessibility

UniCircle is being tested against WCAG 2.2 AA principles. This is a development statement, not a claim that every part has passed an independent audit.

What is built in

  • keyboard-accessible navigation, forms and dialogs;
  • a skip link and clear heading structure;
  • text labels for controls and alternatives for meaningful images;
  • visible focus states and reduced-motion support;
  • responsive layouts for phone, tablet and desktop;
  • status messages that can be announced by assistive technology.

Latest in-project check

On 14 October 2026, the main signed-out and signed-in journeys were checked in Chrome at 320, 375, 390, 430, 768, 1024 and 1440 CSS pixels. The check found no horizontal page overflow, duplicate HTML identifiers, unnamed visible links or buttons, or images without alternative text. Mobile navigation, focus return and scrollable dialogs were also checked.

Known limits

This check is not an independent WCAG audit. Real-device Safari and Android testing, multiple screen-reader and browser combinations, browser zoom and reflow beyond the checked widths, live calls, third-party meeting providers, generated illustrations and future university integrations still need additional accessibility testing.

Reporting a barrier

During the pilot, record the device, browser, page and task in the Pilot Test Centre. A university deployment must publish an approved accessibility contact and response process.
